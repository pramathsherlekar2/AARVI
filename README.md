# Aarvi – Care that Connects ❤️

**A smarter, more connected elderly-care and medication-management platform.**

Aarvi helps elderly individuals, family members, and caregivers coordinate daily healthcare activities through one accessible, connected platform.

## 🌟 Key Features

- **Role-Based Dashboards:** Separate experiences for elderly patients, family members, and caregivers.
- **Patient Profiles:** Organised patient information and care coordination.
- **Medication Management:** Medication schedules, dose tracking, and adherence monitoring.
- **Missed Dose Intelligence:** Identify potentially missed or unconfirmed doses.
- **Appointment Management:** Keep track of upcoming medical appointments.
- **Digital Care Handover:** Share care updates between family members and caregivers.
- **Daily Care Companion:** Maintain daily care notes and updates.
- **Medication Refill Tracker:** Monitor medication inventory and refill needs.
- **AI Care Assistant:** Gemini-powered assistance for understanding authorised care information.
- **Multilingual Experience:** English, Hindi, Marathi, Tamil, Telugu, and Kannada.
- **Offline-First PWA:** Access authorised cached information and queue supported actions offline.
- **Secure Data Management:** Supabase authentication, database policies, and role-based access.

## 🛠️ Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Google Gemini API
- IndexedDB / Dexie.js
- Progressive Web App (PWA)

## 🏗️ Architecture

Aarvi is designed around three primary user roles:

1. Elderly Patient
2. Family Member
3. Caregiver

The platform aims to improve communication, medication adherence, and continuity of care.

## 🔐 Security

- Role-based access control
- Secure authentication
- Supabase Row Level Security (RLS)
- Protected environment variables
- Controlled access to patient information
